## Installation

#### DeepRUOTv1 version
1. Clone this repository:

```vim
git clone https://github.com/zhenyiizhang/DeepRUOT
```

2. You can create a new conda environment (DeepRUOT) using

```vim
conda create -n DeepRUOT python=3.10 ipykernel -y
conda activate DeepRUOT
```

3. Install requirements and DeepRUOT
```vim
cd path_to_DeepRUOT
pip install -r requirements.txt
pip install -e .
```
#### DeepRUOTv2 version

We recommend use the DeepRUOTv2 version. If you use DeepRUOTv2 version, you can install it through:

1. Clone this repository:

```vim
git clone https://github.com/zhenyiizhang/DeepRUOTv2
```

2. You can create a new conda environment (DeepRUOTv2) using

```vim
conda create -n DeepRUOTv2 python=3.10 ipykernel -y
conda activate DeepRUOTv2
```

3. Install requirements
```vim
cd path_to_DeepRUOTv2
pip install -r requirements.txt
```
